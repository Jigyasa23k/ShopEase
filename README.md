# ShopEase – E-Commerce Shopping Cart Web Application

## Overview
ShopEase is a full-stack e-commerce shopping cart web application developed using Spring Boot, Thymeleaf, and MySQL. The project provides an online platform where users can browse products, add items to cart, and manage purchases, while administrators can manage products, categories, and CMS pages through an admin dashboard.

This project demonstrates the implementation of MVC architecture, CRUD operations, session handling, database connectivity, and responsive web design using Java technologies.

---

## Features

### User Features
- Browse products by category
- View product details
- Add products to shopping cart
- Update cart quantity
- Remove items from cart
- Responsive UI design

### Admin Features
- Admin login system
- Add/Edit/Delete products
- Manage product categories
- Manage CMS pages
- Upload product images
- Product inventory management
